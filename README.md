# PDF压缩工具 (PDF Compressor)

一个简单易用的PDF压缩工具，支持图形界面操作，可快速将PDF文件压缩到指定大小。

## ✨ 功能特点

- 🖥️ **图形界面** - 简单易用的窗口界面，无需命令行操作
- 📁 **文件选择** - 支持浏览选择PDF文件和保存位置
- 🎯 **三档压缩质量** - 低(文件最小)、中(推荐)、高(质量好)
- 📏 **目标大小设置** - 可设置目标文件大小
- 📊 **进度显示** - 实时显示压缩进度
- 🔍 **自动查找** - 自动查找系统中的Ghostscript

## 📋 系统要求

- Windows 7/8/10/11
- Python 3.6+
- Ghostscript (程序会自动查找)

## 🚀 使用方法

### 方式一：直接运行Python脚本

1. 确保已安装Python和Ghostscript
2. 双击运行 `PDF压缩工具.py`
3. 点击"浏览..."选择要压缩的PDF文件
4. 选择保存位置（自动推荐）
5. 选择压缩质量（推荐"中"）
6. 点击"开始压缩"
7. 等待完成，查看结果

### 方式二：命令行使用

```bash
python PDF压缩工具.py
```

## ⚙️ 压缩参数说明

| 质量级别 | 分辨率 | 适用场景 |
|---------|--------|---------|
| 低 | 50 DPI | 仅需查看内容，文件最小 |
| 中 | 60 DPI | 平衡质量和大小，推荐 |
| 高 | 100 DPI | 需要较好质量 |

## 🔧 技术原理

本工具使用Ghostscript进行PDF压缩，主要技术参数：

- **PDFSETTINGS**: 控制整体压缩质量
- **ColorImageResolution**: 彩色图片分辨率
- **GrayImageResolution**: 灰度图片分辨率
- **MonoImageResolution**: 单色图片分辨率
- **DownsampleImages**: 图片下采样
- **CompressFonts**: 字体压缩
- **SubsetFonts**: 字体子集化

## 🐛 常见问题

### Q: 提示"未找到Ghostscript"
A: 请安装Ghostscript并确保其在系统PATH中，或将其安装在默认路径。

### Q: 压缩后文件仍然很大
A: 尝试选择"低"质量级别，或检查原PDF是否主要是文字内容。

### Q: 压缩后图片模糊
A: 选择"高"质量级别，或提高目标大小限制。

### Q: 程序无法启动
A: 确保已安装Python 3.6+，并检查tkinter是否可用。
